## 📊 Overview

This dashboard provides a reactive data exploration interface using R's classic `mtcars` dataset. It features a sleek dark mode UI, dynamic filtering, real-time KPI metrics, interactive data plots with hover details, and a searchable data table.

---

## ✨ Features & Highlights

| Feature | Description | Tech Stack |
| :--- | :--- | :--- |
| 🎨 **Dark Theme** | Modern dark UI preset (`darkly`) | `bslib` |
| ⚡ **Dynamic Filtering** | Instant chart & metric updates | Reactive `Shiny` |
| 📈 **Interactive Visuals** | Hover tooltips, zoom, and trend lines | `ggplot2` + `plotly` |
| 📋 **Data Table** | Paginated and filterable table | `DT` |
